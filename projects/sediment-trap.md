## Overview

Sediment Trap is a moored sampler with six timed collection bottles and a
mechanical release driven by a small cam timer. It is lowered to the river bed
and recovered by a single surface line.

## Field notes

Bottles are pre-weighed in the lab and the trap is deployed for 72-hour
windows. The frame is galvanised before each season.

## Documentation

Mechanical drawings are held by the workshop; no public package repository has
been set up for this project yet.
